Configuring an Extra Network Interface on pfSense in VirtualBox

In this module, we’ll walk through adding an extra network interface (5+) on Virtualbox

Configuring an Extra Network Interface on pfSense in VirtualBox​

In the VirtualBox interface, only 4 tabs are available to configure network adapters for a VM. However, it's possible to add up to 8 network interfaces per VM through additional configuration.

Using the VirtualBox CLI (On Windows)​

To add additional interfaces to pfSense, we’ll use the VirtualBox command-line tool, vboxmanage.exe.

On powershell

PS C:\> cd '.\Program Files\Oracle\VirtualBox\'

In this example, I'm using PowerShell within the Windows CMD Terminal .

On my system, VirtualBox is installed in C:\Program Files\Oracle\VirtualBox. Let’s navigate to that directory and run vboxmanage.exe to explore its functionality. Running the command displays general usage instructions, and further down, you'll find a comprehensive list of available commands and their options.

documentation for vboxmanage.exe : https://www.virtualbox.org/manual/ch08.html

Information We Need to Add the Interface​

details For the SOC (defense) interface are as follows:

  • VM Name: Homelab Firewall - PfSense (case sensitive)
  • Next Interface ID: 5 (interface number)
  • Network Name: Homelab - SOC

Shutdown the pfSense VM and run these commands to add the SOC interface :

On powershell

# note the '5' in each option — these flags configure the VM’s fifth (5) network adapter:

.\VBoxManage.exe modifyvm "Homelab Firewall - PfSense" --nic5 intnet
.\VBoxManage.exe modifyvm "Homelab Firewall - PfSense" --nictype5 virtio
.\VBoxManage.exe modifyvm "Homelab Firewall - PfSense" --intnet5 "Homelab - SOC"
.\VBoxManage.exe modifyvm "Homelab Firewall - PfSense" --cableconnected5 on

Notice the new adapter Adapter 5 that shows up in virtualbox

Start the pfSense VM. You’ll notice that only four interfaces are listed—this is expected, as the newly added interface hasn’t been brought up yet.

Notice the new adapter OPT3 that shows up in PfSense

We’ll now repeat some of the steps covered earlier in the "Deploying a pfSense VM for Our VirtualBox-Based Cyber Lab" section. Screenshots won’t be included here, since they’re already provided in that section.

Select Option 1) Assign interfaces from the pfSense console menu.

  • Should VLANs be set up now [y|n]? : n
  • Enter the WAN interface name or ‘a’ for auto-detection: vtnet0
  • Enter the LAN interface name or ‘a’ for auto-detection: vtnet1
  • Enter the Optional 1 interface name or ‘a’ for auto-detection: vtnet2
  • Enter the Optional 2 interface name or ‘a’ for auto-detection: vtnet3
  • Enter the Optional 3 interface name or ‘a’ for auto-detection: vtnet4
  • do you want to proceed ? y

Configure the SOC interface (OPT3)​

Here, we configure the OPT3 (SOC) interface by assigning static IPv4 address and enabling the DHCP server:

  • Choose the interface number corresponding to the OPT1 (in this case, 5).
  • When prompted, decline DHCP for the LAN interface by typing n.
  • Enter the desired static IP address (10.150.150.1) and subnet mask bit count (24 for a /24 subnet).
  • Leave the upstream gateway blank by pressing ENTER.
  • Disable IPv6 configuration by typing n.
  • Enable the DHCP server on OPT3 by typing y, then specify the DHCP range (start: 10.150.150.11, end: 10.150.150.100).
  • Answer n to reverting to HTTP as the webConfiguraor protocol.
